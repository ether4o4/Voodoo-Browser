Compatibility & lifecycle

Supports @match, @exclude-match, @run-at, and GM_addStyle / GM_getValue / GM_setValue / GM_deleteValue. Scripts run in the top page's JavaScript context. GM values belong to that website's local storage and are visible to its scripts. Internal Voodoo pages are excluded. This is a userscript runner, not the full Tampermonkey extension.

Disabling a script stops future automatic injections. Reload the target page to remove its existing timers and DOM changes. “Run once” can duplicate effects; reload first when testing. Android can pause pages in the background.

Your choice of AI.
Venice, OpenAI, OpenRouter, and Groq use the compatible chat format. Other services can use a custom HTTPS base URL.
Keys are encrypted with Android Keystore. They never enter website scripts or exported backups. API requests go directly to the endpoint you configure.
Changing the endpoint requires re-entering its key. New chats can use another provider; the active chat stays with its provider until you start a new chat.
Subscriptions to chat apps generally do not supply API credit. Choose a text/code model available to your API account.

How updates work
Install a newer Voodoo APK over this app, signed with the same key, to retain the profile and settings. Do not uninstall first. Android System WebView updates the browsing engine separately. Clearing app data or uninstalling removes local data and API keys.
The Suno loop uses page status changes and random delays, without AI. It pauses when the app loses focus or you switch tabs. Keep Suno visible to continue.
